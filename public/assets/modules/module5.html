DIMENSIONALITY REDUCTION

Academic Module | Machine Learning | 30-Page Study Module

A detailed academic explanation of why high-dimensional data is difficult to analyze, how dimensionality reduction works, major linear and nonlinear methods, practical workflows, evaluation, and common mistakes.

1. Introduction & The Curse of Dimensionality

Dimensionality reduction represents high-dimensional data using a smaller number of informative components while preserving essential structural information. As dimensions increase, data points become extremely sparse, distance metrics (e.g., Euclidean distance) concentrate and lose discriminative power, storage requirements soar, and models risk severe overfitting.

2. Preprocessing & Feature Scaling

Variance-based methods such as PCA are highly sensitive to variable scales. A feature measured in millions will dominate variance over a feature measured in units between 0 and 1. Standardization (Z-score scaling: mean 0, unit variance) is critical before computing principal components.

3. Principal Component Analysis (PCA)

PCA is an unsupervised linear technique that rotates coordinates to align with directions of maximum data variance:

  • First Principal Component (PC1): Captures the largest direction of variance in the feature space.
  • Second Principal Component (PC2): Orthogonal (uncorrelated) to PC1, capturing the maximum remaining variance.
  • Mathematical Foundation: Computed via the eigendecomposition of the covariance matrix Σ = V Λ V^T or Singular Value Decomposition (SVD) of the centered data matrix X = U Σ V^T.

4. Choosing Dimensionality: Scree Plots & Explained Variance

The explained variance ratio quantifies the proportion of dataset variance captured by each component. Selection strategies include cumulative variance thresholds (e.g., retaining components that explain 90% or 95% total variance) and identifying the elbow point on a scree plot.

5. Supervised vs Unsupervised: Linear Discriminant Analysis (LDA)

While PCA maximizes total variance without regard to class labels, LDA is a supervised technique that finds linear combinations maximizing between-class scatter relative to within-class scatter. For C classes, LDA yields at most C - 1 discriminant dimensions.

6. Nonlinear Dimensionality Reduction & Manifold Learning

When data lies on curved, nonlinear manifolds, linear projections fail to preserve neighborhood topology:

  • Kernel PCA: Uses kernel functions (RBF, polynomial) to compute PCA in an implicit high-dimensional Hilbert space.
  • t-SNE (t-Distributed Stochastic Neighbor Embedding): Preserves local pairwise probabilities using a Student-t distribution in the low-dimensional embedding; premier tool for 2D/3D cluster visualization.
  • UMAP (Uniform Manifold Approximation and Projection): Graph-theoretical manifold reduction preserving both local neighborhood structure and global continuum, often faster than t-SNE.
  • Autoencoders: Neural network bottleneck architectures trained to reconstruct input data, learning flexible nonlinear latent representations.

7. Practical Machine Learning Workflow

In predictive pipelines, dimensionality reduction must be treated as a learned transformer fit strictly on training folds to prevent test set data leakage. Downstream model accuracy, reconstruction error, and computational latency determine final dimensionality choice.
