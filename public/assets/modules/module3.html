1. Introduction to Feature Selection and Decision Trees

Machine-learning models often receive many input variables, but more features do not automatically produce higher accuracy. Feature selection removes noisy, irrelevant, redundant, or costly predictors. Decision trees then offer a clear, transparent hierarchical structure for making data-driven decisions.

2. Major Feature Selection Approaches

CategoryMechanismKey StrengthsLimitations
Filter MethodsEvaluates features independently of model (Correlation, Chi-Square, ANOVA, Mutual Information)Fast, scalable, model-agnosticIgnores feature interactions; may retain redundant features
Wrapper MethodsEvaluates feature subsets using model performance (Forward selection, Backward elimination, RFE)Captures feature interactionsComputationally expensive; risk of overfitting without cross-validation
Embedded MethodsPerforms selection internally during training (L1 Lasso, tree feature importance)Balances accuracy and efficiencySpecific to the chosen learning algorithm

3. Correlation, Redundancy and Multicollinearity

Redundant features duplicate information already provided by other variables (e.g., height in cm vs meters). In linear and logistic models, multicollinearity inflates coefficient variance and complicates interpretability. Mutual information helps detect complex nonlinear dependencies that linear correlation misses.

4. Preventing Data Leakage

Target Leakage: Including variables created or recorded after the outcome occurred.

Preprocessing Leakage: Performing scaling, encoding, or feature selection on the complete dataset prior to splitting into train/validation folds. Feature selection must always be fit exclusively on training data.

5. Decision Tree Structure & Splitting Logic

Decision trees recursively partition feature space into rectangular regions:

  • Root Node: Topmost decision node representing the entire dataset.
  • Internal Nodes: Tests applied to specific features (e.g., income > 50,000).
  • Branches: Outcomes of the split test.
  • Leaf Nodes: Final terminal prediction (class label or numerical mean).

6. Splitting Criteria: Gini Impurity and Entropy

  • Gini Impurity: Measures class heterogeneity: 1 - Σ(p_i²). A pure node has Gini = 0.
  • Entropy: Measures information uncertainty: -Σ p_i log&sub2;(p_i).
  • Information Gain: Reduction in entropy achieved by partitioning on a given feature split.
  • Regression Trees: Minimize Mean Squared Error (MSE) or Mean Absolute Error (MAE) within child leaves.

7. Controlling Tree Complexity & Pruning

Unconstrained trees grow until every leaf is pure, memorizing training noise (overfitting). Complexity is regulated via:

  • Pre-pruning hyperparameters: max_depth, min_samples_split, min_samples_leaf, max_leaf_nodes.
  • Post-pruning: Cost-complexity pruning (minimal cost-complexity parameter α) removes branches providing insufficient validation gain.

8. Evaluation and Rule Interpretability

Classification trees are evaluated via Confusion Matrix, Precision, Recall, F1-Score, and ROC-AUC. Every path from root to leaf translates directly into human-readable IF-THEN decision rules.
