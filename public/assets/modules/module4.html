1. Introduction to Ensemble Learning

Ensemble learning combines predictions from multiple models to create a stronger, more robust predictor. By combining diverse base learners whose individual errors are uncorrelated, the ensemble achieves superior accuracy and reduced variance.

3. Bagging and Bootstrap Sampling

From dataset of size n, a bootstrap sample of size n is drawn with replacement. Approximately 63.2% of instances appear in each sample, leaving ~36.8% as Out-of-Bag (OOB) data. OOB samples provide free validation performance estimates without requiring an explicit validation split.

4. Random Forest: Architecture & Random Feature Selection

Random Forests extend bagging by adding feature randomness at every split: rather than searching all features, only a random subset (typically √p for classification, p/3 for regression) is evaluated. This decorrelates individual trees, dramatically lowering overall forest variance.

5. Boosting: AdaBoost and Gradient Boosting

  • AdaBoost: Sequentially reweights misclassified training instances, forcing subsequent weak learners to concentrate on difficult cases.
  • Gradient Boosting: Fits each successive tree to the negative gradient (pseudo-residuals) of a differentiable loss function (e.g., squared error, cross-entropy).
  • Key Hyperparameters: Learning rate (η), number of estimators, maximum depth, and subsample ratio (stochastic gradient boosting).

6. Modern Gradient Boosting Ecosystem

  • XGBoost: Extreme Gradient Boosting with exact greedy/approximate split finding, L1/L2 tree regularization, and hardware acceleration.
  • LightGBM: Uses histogram-based binning and leaf-wise (best-first) tree growth for ultra-fast training on massive tabular data.
  • CatBoost: Specialized ordered boosting and target encoding for handling categorical features with minimal data leakage.

7. Stacking, Blending & Model Diversity

Stacking trains a Level-1 meta-model on out-of-fold cross-validated predictions generated by diverse Level-0 base learners. Diversity in algorithms, feature subsets, and inductive biases is essential for maximizing ensemble gains.
